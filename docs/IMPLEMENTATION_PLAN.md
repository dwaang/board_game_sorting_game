## Этап 5 — Центральная обработка правильной установки

Один общий путь для всех способов установки.

Должен обрабатывать:
- [ ] первую награду коробки;
- [ ] +1 SP только один раз;
- [ ] перезарядку активных навыков;
- [ ] правило 30 секунд;
- [ ] проверку серии;
- [ ] проверку франшизы;
- [ ] изменение save-state;
- [ ] сигналы/UI/audio/network hooks.

Правило 30 секунд:
- первая правильная установка может уменьшить recharge;
- повторная установка уменьшает recharge только через >= 30 секунд после предыдущей засчитанной установки этой коробки;
- установка раньше 30 секунд recharge не уменьшает;
- повторная установка никогда не даёт второй +1 SP.

Не дублировать эту логику в ручной установке и броске.
